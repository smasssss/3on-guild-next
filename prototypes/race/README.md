# 엉뚱 경주 시안

'추첨 게임' 탭에 넣을 세 번째 게임의 시안입니다. 아직 사이트에 연결하지 않았습니다.

- `sim.mjs` : 경기 계산. 같은 추첨 번호(seed)면 언제나 같은 경기입니다. 열한 종류 가운데 누가 몇 번을 달지도 추첨 번호로 정하고, 한 종류는 한 경기에 한 번만 나옵니다.
- `view.mjs`, `index.html` : 계산한 경기를 다시 보여 주는 화면(선두 카메라, 웃긴 장면 클로즈업, 뒤쪽 카메라와 작은 선두 화면). 주소 뒤에 `#seed=e1bfedc3&n=10` 을 붙여 봅니다.
- `check.mjs` : 종류별 우승·꼴찌 비율과 경기 시간 확인. `balance.mjs` : 열한 종류가 비슷하게 우승하도록 값을 맞추는 도구. `find.mjs` : 보고 싶은 사건이 나오는 추첨 번호 찾기.
- `assets/` : 선수 그림(달리는 동작 네 장씩, 판다는 한 장), 캥거루·UFO·오토바이 등 소품, 경기장 배경. 모두 직접 만든 그림입니다.

보는 법: 이 폴더에서 `python3 -m http.server 8782` 를 켜고 `http://localhost:8782/index.html` 을 엽니다.
