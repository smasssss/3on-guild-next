# 엉뚱 경주 시안

'추첨 게임' 탭에 넣을 세 번째 게임의 시안입니다. 아직 사이트에 연결하지 않았습니다.

- `sim.mjs` : 경기 계산. 같은 추첨 번호(seed)면 언제나 같은 경기입니다. 번호 1~10에 어떤 선수가 들어갈지도 추첨 번호로 정합니다.
- `view.mjs`, `index.html` : 계산한 경기를 다시 보여 주는 화면. 주소 뒤에 `#seed=00c51d27&n=10` 을 붙여 봅니다.
- `check.mjs` : 선수 종류별 우승 횟수·경기 시간 확인. `balance.mjs` : 종류별 속도를 고르게 맞추는 도구.
- `assets/` : 선수 그림(달리는 동작 두 장씩, 판다는 한 장)과 경기장 배경. 모두 직접 만든 그림입니다.

보는 법: 이 폴더에서 `python3 -m http.server 8782` 를 켜고 `http://localhost:8782/index.html` 을 엽니다.
