# VIP 주간 자격 개편

기준: 사용자 전체 사양 및 `3ON_Codex_handoff_20261028.md`. 운영 소스는
`8caefa5c8b0259f847ab72180016d045d8566f60`, tree `33e268bb165d0c3f7eb0c41db32a85eddfdd9b90`.

## 범위와 보존

기존 Cron, 수집 검증, 성장·협곡·마차 이력, VIP_IMPORT의 999 기초값,
공주 기초값 1, vipCarry/vipResolution, 회원 ID별 영구 제외, 날짜 선택과
사용자 지정 7명 로테이션을 보존한다. INCOMPLETE_ROSTER는 별도 문제다.
자동수집이나 외부 API 호출을 추가하지 않는다.

## 설계

- 저장된 최신 완전 로스터의 관측과 confirmed 게임 ID 연결에서 마차 명단을 읽는다.
  미관측은 선택 대상에서만 제외하며 탈퇴 확정이나 기존 기록 삭제를 하지 않는다.
  검토 중인 동일인·재가입은 확인 전 선택 불가. canonical과 member_id를 함께 보존한다.
- 기존 documents/backups에 독립 `vip-weekly` 문서 한 개를 추가한다.
  기존 `/api/state`의 세 문서 계약과 기존 carriage payload를 유지한다.
  새 테이블·마이그레이션은 필요하지 않다. 점수 문서는 current/pending 두 슬롯만 가진다.
- 토요일 providedOn, 그 다음 월요일 appliesOn, coverage(full/partial),
  memberId/nickname/points를 포함한 JSON을 기존과 같은 파일 선택 방식으로 검증한다.
  점수는 정수, 정확한 닉네임과 명시된 회원 ID를 함께 확인한다. 이름 자동보정·유사 매칭 금지.
  full은 현재 명단 전체와 일치해야 한다. partial 누락자는 unknown이며 0으로 만들지 않는다.
- Monday KST 경계에서 읽기 시 유효 슬롯을 결정한다. 새 Cron이나 전원 갱신 쓰기 없이
  즉시 전환하고, 다음 업로드에서 슬롯을 정리한다. 새 자료가 없으면 마지막으로 적용한 점수와 자격을 유지한다. 새 자료는 월요일부터 대체하며 합산하지 않는다.
  같은 주 수정은 그 주만 대체한다. 동일 자료 재전송은 문서 revision·백업도 증가시키지 않는다.
- 초기 주차 및 첫 점수 적용 전에는 지정 16명 임시 제한. 기존 확정 canonical/alias와 게임 ID의
  회원 연결을 사용한다. 첫 점수 적용 월요일(최초 11-02)부터 점수 >=21,720,000, 새 주 자료 미제공 시 마지막 자료 유지, 해당 자료 내 개인 점수 누락은 선택 불가.
  그 전까지 나머지 인원은 기존 규칙을 유지한다. 영구 제외가 항상 최우선이다.
- 자격은 서버 현재 KST 주차로 판단한다. 운행일이 다른 주라도 현재 자격을 우회할 수 없다.
  기존 동일 VIP 기록의 메모 수정 등은 재선정으로 취급하지 않는다. 신규·교체 VIP만 검사한다.
  새 기록에는 vipMemberId를 저장하고, 구기록은 보존한다.
- UI의 VIP 버튼과 클릭 처리, `/api/state`의 신규·교체 VIP 저장 모두 같은 자격을 검사한다.
  주간 점수 전용 경로는 carriage를 쓰지 않으며 일반 백업 복원으로 점수/영구 제외를 지우지 않는다.
- 마차 선택기·미리보기에는 주간 점수와 주차·갱신시각을 표시한다. 성장 데이터의 power는 유지한다.

## 배포 경계

로컬 fixture에서 개발·검증한다. Cloudflare 인증, active version/설정 확인,
전체 D1 백업 및 복구 검증이 완료되기 전 원격 변경·배포 금지.
과거 배포 workflow를 그대로 재실행하지 않는다.

## 사용자 운영 규칙 변경

새 주 자료가 없을 때 이전 점수·자격을 유지한다는 후속 지시가 기존 미제공 차단 규칙보다 우선한다.
원래 자료 주차와 갱신시각은 유지하고, 현재 운영 주차와 구분하여 표시한다.
최초 점수가 없는 현재는 자동수집 명단과 마차 명단을 맞추고 기존 영구 제외 및 지정 16명 제한만 적용한다.
첫 자료가 실제 월요일에 적용되기 전까지 나머지는 기존 자격을 유지하며, 첫 적용 시점부터 점수로 재판정한다.
